1.1 Introduction

Algorithm visualization is a powerful pedagogical tool that bridges the gap between abstract theory and intuitive understanding. Traditional teaching relies on static diagrams and pseudocode — formats that struggle to convey the dynamic, step-by-step nature of how algorithms actually behave in memory. The Algorithm Visualizer & IDE project addresses this by providing an interactive, browser-based platform where learners can watch algorithms execute in real time.

This is more than a visualizer — it is a complete learning ecosystem. It pairs a professional code editor, a multi-language compiler (C, C++, Python), a curated catalogue of competitive programming problems, and an AI-powered assistant into a single seamless workflow. The goal is a true "one-stop solution" for university students and competitive programmers alike.

1.2 Problem Statement

Students often struggle to picture how data physically moves through memory during a sort, or how pointers shift while traversing a linked list. Worse, switching between editors, compilers, documentation, and tutorial sites constantly disrupts the learning flow. There is a clear need for a unified platform that integrates visualization, execution, and guided learning in one place.

⚠ Pain Points Today

  • Setting up local C/C++ toolchains is a barrier for first-year students.
  • Static textbook diagrams cannot show state transitions over time.
  • Disconnected tools — IDE, visualizer, judge, notes — break concentration.
  • No personalised feedback when a learner gets stuck on a concept.

CHAPTER 02

System Architecture & Tech Stack

The application is built as a modern Single Page Application (SPA) with a client-heavy architecture. Most processing — including Python execution and AI inference — happens directly inside the browser or via lightweight stateless API calls, keeping the system fast, private, and inexpensive to operate.

2.1 Frontend Foundation

React 18 Vite 5 Tailwind CSS TypeScript Framer Motion React Router

React 18's concurrent renderer and component lifecycle make it ideal for the high-frequency UI updates required to animate sorting bars at 60 frames per second. Vite provides instant dev-server start and Hot Module Replacement, dramatically tightening the feedback loop during development.

💡 Why Tailwind CSS?

Utility-first styling lets us prototype UI variations without context-switching to separate stylesheets. Combined with a custom design-token layer, the entire app stays visually consistent across light and dark themes and adapts cleanly from mobile to ultra-wide displays.

Sorting & Searching Visualization

The visualization engine is the heart of the application. It pairs React state with CSS transitions to animate data flow smoothly while keeping the underlying algorithmic step-trace inspectable, frame by frame.

3.1 Sorting Algorithms (5 Types)

Each sort emits a stream of step descriptors that the renderer translates into colour-coded bar transitions.

3.2 Searching Algorithms (5 Types)

Searching modules accept a target value and visualise pointer movement, mid-points, and probe positions in real time.

🔎 Linear Search

Scans element-by-element; works on unsorted data. Best baseline for beginners.

📐 Binary Search

Halves the search space each iteration on a sorted array. Mid-pointer highlighted.

🦘 Jump Search

Jumps √n steps then linearly scans backward — a sorted-array compromise.

🌀 Fibonacci Search

Uses Fibonacci numbers to partition the array; useful when division is expensive.

🎯 Interpolation Search

Estimates probe position from boundary values — near-O(log log n) on uniform data.

🔁 Exponential Search

Doubles the range until the target is bracketed, then binary-searches inside it.

Step-trace Generator (excerpt)

// Bubble sort emits a step trace for the renderer
function bubbleSort(arr) {
  const steps = [];
  for (let i = 0; i < arr.length; i++) {
    for (let j = 0; j < arr.length - i - 1; j++) {
      steps.push({ type: "compare", indices: [j, j+1] });
      if (arr[j] > arr[j+1]) {
        [arr[j], arr[j+1]] = [arr[j+1], arr[j]];
        steps.push({ type: "swap", indices: [j, j+1] });
      }
    }
    steps.push({ type: "sorted", index: arr.length - i - 1 });
  }
  return steps;
}

4.2 Graphs & Trees (Interactive Canvas)

The graph module is the most ambitious surface in the app. It uses an SVG layer for rendering and a custom force-aware layout to keep nodes legible as the user manipulates the structure.

＋

Add Node

Click on empty canvas to spawn a vertex with an auto-incrementing label.

↔

Add Edge

Drag from one node to another to create a directed or undirected edge.

⇄

Move Node

Reposition vertices freely so users can untangle dense graphs.

Traversal Visualization (BFS / DFS)

During traversal, the canvas paints the current node in blue, visited nodes in green, and frontier neighbours in amber. A side panel mirrors the live state of the auxiliary queue (BFS) or stack (DFS), so learners can correlate the data structure with the on-screen exploration.

🌳 Tree Mode

Trees are a special case of graphs. The system auto-layers nodes hierarchically (root at top, children fanned out below) but still allows free editing — perfect for testing custom BSTs, heaps, or expression trees.

CHAPTER 05 & 06

Compiler, AI, Roadmaps & Conclusion

5.1 Online IDE & LeetCode Hub

The Compiler module embeds CodeMirror 6 with custom themes that match the app's design language. It feels like a desktop editor, but lives entirely in the browser tab.

⌨

Multi-language

Switch instantly between C, C++, and Python with per-language defaults and templates.

📥

Stdin Box

Dedicated standard-input panel — essential for competitive-programming style problems.

📤

Output Console

Real-time stdout, stderr, and structured compile diagnostics with line numbers.

LeetCode 100 Hub

A curated, locally-bundled JSON catalogue of 150 high-yield problems, filterable by difficulty (Easy / Medium / Hard) and topic (Arrays, DP, Graphs, Trees, Strings, Greedy, ...). Each card links out to LeetCode for submission and "Open in IDE" lets the user solve it inside the integrated compiler.

5.2 AI Tutor

"Why did Quick Sort just choose that element as the pivot?" — the AI tutor answers in plain English, scoped to the algorithm currently on screen.

5.3 Learning Roadmaps (C & C++)

To onboard absolute beginners, the app ships a 10-chapter roadmap for both C and C++. Each chapter contains:

  • Theory notes with diagrams.
  • Runnable code samples that open in the integrated IDE.
  • Multiple-choice quizzes with instant feedback.
  • Curated external resources (YouTube, GeeksforGeeks, cppreference).

Progress is persisted in LocalStorage, so closing the tab never loses a learner's place — no account required.

6. Conclusion

The Algorithm Visualizer & IDE successfully unifies visualization, execution, and structured learning into a single responsive web application. By leaning on modern technologies — React 18, Pyodide, CodeMirror 6, and Tailwind — the project delivers a fast, polished, and pedagogically meaningful experience that scales from first-year students to working competitive programmers.
